# PCAN-LabVIEW-API5x Demo
Peak PCAN, LabVIEW API 5.x for CAN Bus

This is a Demo for PCAN DLL5.
This API support CAN2.0, CAN-FD and CAN-XL.
Support of LabVIEW 2020 or higher.

The API is designed for the free PCAN-Basic AP for Connecting to CAN CC, CAN FD and CAN XL Buses.
